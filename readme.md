# Cloudflare 优选 IP 测试说明（黑龙江哈尔滨 · 联通网络）

本项目针对 **黑龙江哈尔滨联通** 网络环境，持续对 Cloudflare 优选 IP 进行筛选与测试，并提供稳定的域名绑定服务。

---

## 📅 每日更新（Daily）

- **测试样本**：从 `CFST` 默认抽取的 **5955 个 IP** 中筛选。
- **筛选规则**：  
  - 丢包率 = 0  
  - 带宽 ≥ 10 Mb/s  
  - 延迟 ≤ 250 ms  
- **输出结果**：取满足条件的前 **200 名** IP。
- **测试频次**：每天 **早上 4:00** 和 **晚上 20:00** 各执行一次。
- **域名绑定**：每日测试结果的 **前 10 名** IP 将自动绑定至：  
  `cf.345.dpdns.org`

> ⚠️ 注：此前曾包含香港 IP，但目前测试结果中已不再出现，原因暂不明。

---

## 📆 每周更新（Weekly）

- **数据来源**：汇总最近 **三周** 每日测试中出现的高频优质网段，进行专项测试。
- **筛选规则**（同每日标准）：  
  - 丢包率 = 0  
  - 带宽 ≥ 10 Mb/s  
  - 延迟 ≤ 250 ms  
- **输出结果**：取满足条件的前 **200 名** IP（旨在发现更多优质节点）。
- **测试频次**：每周更新一次。
- **域名绑定**：每周测试结果的 **前 10 名** IP 将自动绑定至：  
  `cfyx.345.dpdns.org`

---
